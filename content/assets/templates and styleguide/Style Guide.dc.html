(04)  Typography · Barlow 200 vs Barlow Condensed 800

The core move is extreme weight contrast: extra-light against extra-bold condensed. No middle-weight display type. Fonts: Barlow (200-700), Barlow Condensed (700/800), JetBrains Mono (index numbers only).

Semantic mapping (SEO / web standards): every style below is mapped to a standard tag — H1 through H6, p, or a named class. The mapping renames only; visual specs are locked exactly as designed in the templates and must not change. One H1 per page; heading levels never skip.

(05)  Grid, Gutter & Animated Rails

Gutter: clamp(24px, 4vw, 56px). Five 1px rails at the gutter edges and quarter columns span the FULL page behind content (z-index 5; content wrappers at 6). Pulses sweep down on 26-38s linear loops, alternating orange and grey. Shown here at boosted opacity — production is rgba(128,128,128,0.12).

Section rhythm 96-128px · label column 220px · number column 120px · everything stacks below 760px.

Label duplicated inside .roll; hover rolls it up and the twin rolls in (400ms settle). Arrow nudges ↗ 3px. Press = 2px down. Variants: primary (orange, one per view), dark, ghost. Text links instead use color→orange + translateX settle. EXPLORE NOW rows: orange 14px/700/0.16em + 22px ↗ arrow.

(08)  Icons · Phosphor

Weights — Light is the default

thin · light (default) · regular · bold. Light matches the Barlow 200 display type; use regular/bold only at 16px and below.

Core set

Sizes 16 / 20 / 24 / 32 (never below 14px). Color via currentColor — inherits text color; orange only when the icon IS the action cue (Explore ↗).

Rules: one icon family site-wide, no emoji, no unicode glyph icons in copy. The signature ↗ arrow, hamburger, close X, and sun/moon in the templates map to Phosphor arrow-up-right · list · x · sun · moon (light weight). Astro: use @phosphor-icons/web or per-icon SVG imports from @phosphor-icons/core to keep the build lightweight.

(10)  Forms · Imagery · States · Breakpoints · SEO

Form inputs

No boxes: bottom hairline only, 20px Barlow, uppercase 12px labels, placeholder at 35% opacity. Focus = hairline turns orange. Errors = orange hairline + 13px message. Submit = primary pill. Short forms only (name / email / message).

Imagery treatment

Hero video 1280/600, edge-to-edge, no radius
Full-bleed feature photo 100vh desktop / 52vh mobile, no radius
Gallery thumbs 19:9, 8px radius, 30px gutter
Portraits 4:5 or square, 12px radius
Hover opacity 0.85 + scale 1.07 (700ms settle)
Lightbox 900px wide on rgba(0,0,0,0.9)
Warm, professional, people-forward. No stock slop, no illustrations, no patterns.

Interaction states

Hover color→orange + translateX settle (rows), roll (buttons)
Focus-visible 4px orange glow ring — always visible, never removed
Active 2px press-down
Disabled 40% opacity, no pointer
Current page black label in orange menu
Loading icon mark as spinner (spinSlow)

Breakpoints

≤760px mobile: grids stack, hero 62vh, caption hidden, H1 44px wrapping, 1-col gallery, EXPLORE indents to name
761-1280px fluid via clamp() — no separate tablet layout
>1440px type caps at clamp() maximums
Tap targets ≥44px throughout.
