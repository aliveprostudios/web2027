# Website UI Kit — Alive ProStudios

Recreation of the aliveprostudios.com marketing surface. Components are in `*.jsx`, styles in `kit.css` + `sections.css`. The `index.html` is a click-thru demo featuring a realistic sequence of landing-page sections.

## Components

| File | Exports |
|---|---|
| `TopSections.jsx` | `Nav` (with dropdown flyouts), `Hero`, `Problem` |
| `SystemSections.jsx` | `SystemDiagram` (interactive 4-stage tabs), `Services` (9-tile grid) |
| `BottomSections.jsx` | `Testimonial`, `Stats` (lime band), `CTA`, `Footer` |

## Design notes mirrored from the live site

- **Nav service taxonomy** matches the site's 4-column IA: Foundation / Execution / Growth / Infrastructure.
- **Hero** uses the signature confrontational copy pattern and ends on the orange dot.
- **System section** turns the static PDF diagram into an interactive stage switcher.
- **Stats band** uses brand lime as a full-width color block — the only place the lime dominates a whole section.
- **Footer** is pure black (authority) with lime section labels.
