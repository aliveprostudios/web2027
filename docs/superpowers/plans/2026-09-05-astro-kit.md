# Astro Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract a reusable GitHub template repository, `aliveprostudios/astro-kit`, from the Alive ProStudios Astro site, so a new client site is intake only: brand, sitemap, content.

**Architecture:** The kit is a copy of the Alive repository with every identity value moved into three places (`content/site.md`, the brand block of `tokens.css`, `public/assets/brand/`) and every section derived from `content/landing/`. Routes become thin dispatchers over the sections model; page bodies move into components. Two build guards keep sample content and editorial slips out of production. A kickoff script turns two intake files into the configured repo.

**Tech Stack:** Astro 7 (static, no adapter), TypeScript, Zod content schemas, Node 24 with the built-in `node --test` runner, `sharp` (already installed with Astro) for placeholder images, Cloudflare Workers static assets, GitHub CLI.

**Spec:** `docs/superpowers/specs/2026-09-05-astro-kit-design.md` in the Alive repository.

## Deviations from the spec, decided while planning

Each is small and each makes drift less likely. Say so in the handoff to Javad.

1. `astro.config.mjs` reads `domain` from `content/site.md` at config time, so the site URL has one source. Kickoff never edits `astro.config.mjs`.
2. Brand assets live in `public/assets/brand/`, not `content/assets/brand/`, because `og:image` and favicons need permanent unhashed URLs. Kickoff copies the client's files there under the fixed names.
3. Editorial settings are flat keys in `content/site.md` (`language`, `bannedWords`, `noPricing`, `noEmDash`), not a nested `editorial` object, so the build scripts can read them without a YAML library.
4. Section kinds are `services`, `about`, `work`, `case-studies`, `resources`, `contact`. The spec's `pillar` is split into `services` and `about` because they read different content folders. Blog and Common Questions are Resources children, and legal documents are footer links, as on the Alive site today.
5. Only `services` and `about` sections have free URLs. The URLs of `work`, `case-studies`, `resources`, `contact`, the blog and the questions hub stay fixed in the route files and are validated against the landing file, which throws on a mismatch. Making them free needs a catch-all route dispatcher, which is a second spec. Free group and about URLs are where clients actually differ.
6. Contact copy lives in `content/landing/contact.md`. The `pages` collection is removed.
7. `content/site.md` carries the two or three lines of copy the shared components need (`ctaLines`, `ctaBadge`, `nextStepLines`, `marquee`), because those strings are Alive copy today and rule 3 forbids inventing replacements in code. `BookConsult` renders nothing when `ctaLines` is absent.

```js
/**
 * Shared helpers for the kit's tests. No dependencies: `node --test` only.
 *
 * `build()` runs the real `npm run build` (blog-check, astro build, postbuild)
 * as a STAGING build, so the sample guard passes and the output can be read.
 * `withCopy()` clones the repo into a temp folder, symlinks node_modules, and
 * hands the path to a callback, for tests that mutate files or run kickoff.
 */
import { execSync } from 'node:child_process';
import { cpSync, existsSync, mkdtempSync, readFileSync, rmSync, symlinkSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';

export const root = fileURLToPath(new URL('..', import.meta.url));

export function build(env = {}, cwd = root) {
  execSync('npm run build', {
    cwd,
    stdio: 'pipe',
    env: { ...process.env, STAGING: '1', ...env },
  });
}

/** Like build(), but returns { ok, output } instead of throwing. */
export function tryBuild(env = {}, cwd = root) {
  try {
    const out = execSync('npm run build', {
      cwd,
      stdio: 'pipe',
      env: { ...process.env, STAGING: '1', ...env },
    });
    return { ok: true, output: String(out) };
  } catch (error) {
    return { ok: false, output: String(error.stdout ?? '') + String(error.stderr ?? '') };
  }
}

export function dist(relPath, cwd = root) {
  return readFileSync(join(cwd, 'dist', relPath), 'utf8');
}

export function distExists(relPath, cwd = root) {
  return existsSync(join(cwd, 'dist', relPath));
}

/** Every built HTML file, as [relPath, html]. */
export function distPages(cwd = root) {
  const out = execSync("find dist -name '*.html'", { cwd }).toString().trim().split('\n');
  return out.map((p) => [p.replace(/^dist\//, ''), readFileSync(join(cwd, p), 'utf8')]);
}

const SKIP = new Set(['node_modules', 'dist', '.git', '.astro', '.wrangler', 'tests']);

export async function withCopy(fn) {
  const dir = mkdtempSync(join(tmpdir(), 'astro-kit-'));
  cpSync(root, dir, {
    recursive: true,
    filter: (src) => !SKIP.has(src.replace(root, '').split('/').filter(Boolean)[0] ?? ''),
  });
  symlinkSync(join(root, 'node_modules'), join(dir, 'node_modules'));
  try {
    return await fn(dir);
  } finally {
    rmSync(dir, { recursive: true, force: true });
  }
}
```

- [ ] **Step 5: Write `src/lib/site.ts`**

```ts
import { getEntry } from 'astro:content';
import type { CollectionEntry } from 'astro:content';

/**
 * The one reader of `content/site.md`.
 *
 * `url` is the domain with any trailing slash removed, so `${site.url}${path}`
 * never doubles a slash. Cached for the build: the file cannot change between
 * two pages of the same build.
 */
export type Site = CollectionEntry<'site'>['data'] & { url: string };

let cached: Site | null = null;

export async function getSite(): Promise<Site> {
  if (cached) return cached;
  const entry = await getEntry('site', 'site');
  if (!entry) {
    throw new Error('content/site.md is missing. Run the kickoff skill, or write it from intake/brand.md.');
  }
  if (entry.data.phone && !entry.data.phoneHref) {
    throw new Error('content/site.md: phoneHref is required when phone is set');
  }
  cached = { ...entry.data, url: entry.data.domain.replace(/\/$/, '') };
  return cached;
}

export function absoluteUrl(site: Site, path: string): string {
  return new URL(path, `${site.url}/`).href;
}
```

- [ ] **Step 6: Rewrite `src/lib/sections.ts`**

```ts
import { getCollection, type CollectionEntry } from 'astro:content';

/**
 * The site's sections, derived from `content/landing/`.
 *
 * A section is a landing file. Its `kind` decides which route family builds
 * it and where its children come from:
 *
 *   services       pages in content/services/<id>/, one section per folder
 *   about          pages in content/about/
 *   work           children are the numbered ## rows of the landing file
 *   case-studies   children are the caseStudies collection
 *   resources      children are the numbered ## rows of the landing file
 *   contact        no children
 *
 * services and about choose their own one-segment URL. The other kinds are
 * built by fixed route files, so their URL is checked against the route and a
 * mismatch throws, rather than building a page the menu cannot reach.
 */
export type SectionKind = 'services' | 'about' | 'work' | 'case-studies' | 'resources' | 'contact';

export type Section = {
  /** Landing file id. For services, also the folder under content/services/. */
  id: string;
  label: string;
  url: string;
  /** First path segment: the [section] route param. */
  param: string;
  order: number;
  kind: SectionKind;
  /** "01" for the first staged services section, and so on. Null otherwise. */
  stageIndex: string | null;
};

const FIXED_URLS: Partial<Record<SectionKind, string>> = {
  work: '/work',
  'case-studies': '/work/case-studies',
  resources: '/resources',
  contact: '/contact',
};

export const isPillar = (section: Section): boolean =>
  section.kind === 'services' || section.kind === 'about';

let cache: Section[] | null = null;

export async function sections(): Promise<Section[]> {
  if (cache) return cache;

  const all = await getCollection('landing');
  const published = all
    .filter((e) => e.data.published !== false)
    .sort((a, b) => a.data.order - b.data.order || a.id.localeCompare(b.id));

  let stage = 0;
  const built: Section[] = published.map((e) => {
    const { kind, url } = e.data;
    const fixed = FIXED_URLS[kind];
    if (fixed && url !== fixed) {
      throw new Error(
        `[sections] content/landing/${e.id}.md: a "${kind}" section is built at ${fixed}. Set url: "${fixed}".`,
      );
    }
    if ((kind === 'services' || kind === 'about') && !/^\/[a-z0-9-]+$/.test(url)) {
      throw new Error(
        `[sections] content/landing/${e.id}.md: a ${kind} section needs a one-segment url such as /machining, got ${url}.`,
      );
    }
    const staged = kind === 'services' && e.data.stage;
    if (staged) stage += 1;
    return {
      id: e.id,
      label: e.data.navLabel ?? e.data.title,
      url,
      param: url.split('/')[1]!,
      order: e.data.order,
      kind,
      stageIndex: staged ? String(stage).padStart(2, '0') : null,
    };
  });

  // Every services folder needs a landing file, published or not, or its
  // pages would build with no section to sit in and no menu row to reach them.
  const known = new Set(all.filter((e) => e.data.kind === 'services').map((e) => e.id));
  for (const entry of await getCollection('services')) {
    const group = entry.id.split('/')[0]!;
    if (!known.has(group)) {
      throw new Error(
        `[sections] content/services/${group}/ has no landing file. Add content/landing/${group}.md with kind: services.`,
      );
    }
  }

  cache = built;
  return cache;
}

export async function sectionOfKind(kind: SectionKind): Promise<Section | null> {
  return (await sections()).find((s) => s.kind === kind) ?? null;
}

export async function sectionByParam(param: string): Promise<Section> {
  const found = (await sections()).find((s) => s.param === param && isPillar(s));
  if (!found) throw new Error(`[sections] no services or about section is built at /${param}`);
  return found;
}

/** "Foundation  ·  Stage 01", or the bare label for an unstaged section. */
export function breadcrumb(section: Section): string {
  return section.stageIndex ? `${section.label}  ·  Stage ${section.stageIndex}` : section.label;
}

/**
 * Pages are sequenced by their `order` frontmatter. A page with no `order`
 * falls to the end alphabetically rather than disappearing or landing first,
 * so a new Markdown file shows up with no code change.
 */
export function byOrderThenTitle(
  a: { data: { order?: number | undefined; title: string } },
  b: { data: { order?: number | undefined; title: string } },
): number {

}

```ts
import { getCollection } from 'astro:content';
import { sectionOfKind, type Section, type SectionKind } from './sections';
import { parseLanding, type LandingChild } from './landing';
import { clusters } from './commonQuestions';
import { galleryImages } from './gallery';
import { VIDEO_LIBRARY } from './videos';

/**
 * The hubs: routes with a fixed URL whose content is a collection or a folder.
 *
 * A hub exists only when three things hold: its parent section is published,
 * the parent's landing file lists it as a row (work and resources), and it has
 * at least one item. Null means the hub, its children and its menu entry are
 * all left out, with no code change. That is the empty-section rule applied
 * below the section level.
 */
export type Hub = { section: Section; child: LandingChild | null; count: number };

async function rowOf(section: Section, url: string): Promise<LandingChild | null> {
  const landing = await parseLanding(section.id, section.url);
  return landing?.children.find((c) => c.url === url) ?? null;
}

async function rowHub(kind: SectionKind, url: string, count: () => Promise<number>): Promise<Hub | null> {
  const section = await sectionOfKind(kind);
  if (!section) return null;
  const child = await rowOf(section, url);
  if (!child) return null;
  const n = await count();
  return n > 0 ? { section, child, count: n } : null;
}

export const portfolioHub = () => rowHub('work', '/work/portfolio', async () => galleryImages.length);
export const videosHub = () => rowHub('work', '/work/videos', async () => VIDEO_LIBRARY.length);
export const blogHub = () => rowHub('resources', '/resources/blog', async () => (await getCollection('blog')).length);
export const questionsHub = () => rowHub('resources', '/common-questions', async () => (await clusters()).length);

/** Case Studies is its own section, so it needs no row: the section and a non-empty collection. */
export async function caseStudiesHub(): Promise<Hub | null> {
  const section = await sectionOfKind('case-studies');
  if (!section) return null;
  const n = (await getCollection('caseStudies', (e) => e.data.published !== false)).length;
  return n > 0 ? { section, child: null, count: n } : null;
}

const HUB_OF: Record<string, () => Promise<Hub | null>> = {
  '/work/portfolio': portfolioHub,
  '/work/videos': videosHub,
  '/work/case-studies': caseStudiesHub,
  '/resources/blog': blogHub,
  '/common-questions': questionsHub,
};

/** The rows of a work or resources landing whose hub exists, in row order. */
export async function activeChildren(section: Section): Promise<LandingChild[]> {
  const landing = await parseLanding(section.id, section.url);
  const out: LandingChild[] = [];
  for (const child of landing?.children ?? []) {
    const resolve = HUB_OF[child.url];
    if (!resolve || (await resolve())) out.push(child);
  }
  return out;
}
```

2. Emptying `content/case-studies/` leaves dangling `caseStudies:` references in the question clusters and in `content/home/page.md`, and the build correctly refuses a dangling link. Tests therefore use one helper that removes the studies and the references together:

```js
/**
 * Remove every case study from a copy, and every `caseStudies:` list from the
 * question clusters and the home page, which otherwise fail the build on a
 * dangling link. That failure is correct behaviour; the test removes the edges.
 */
export function emptyCaseStudies(dir) {
  const studies = join(dir, 'content/case-studies');
  for (const f of readdirSync(studies)) rmSync(join(studies, f), { recursive: true });
  const files = [join(dir, 'content/home/page.md')];
  const questions = join(dir, 'content/common-questions');
  if (existsSync(questions)) {
    for (const f of readdirSync(questions)) if (f.endsWith('.md')) files.push(join(questions, f));
  }
  for (const path of files) {
    if (!existsSync(path)) continue;
    const kept = [];
    let skipIndent = -1;
    for (const line of readFileSync(path, 'utf8').split('\n')) {
      const key = line.match(/^(\s*)caseStudies:\s*$/);
      if (key) {
        skipIndent = key[1].length;
        continue;
      }
      if (skipIndent >= 0) {
        const indent = line.match(/^(\s*)/)[1].length;
        if (indent > skipIndent && /^\s*-\s/.test(line)) continue;
        skipIndent = -1;
      }
      kept.push(line);
    }
    writeFileSync(path, kept.join('\n'));
  }
}
```

`tests/helpers.mjs` imports `readdirSync` and `writeFileSync` from `node:fs` for these.

export async function activeSections(): Promise<ActiveSection[]> {

The first part off a new program is an event. Someone holds it up, checks the obvious features, and declares it good. The report that should go with it is often skipped, because the part is right and everyone can see it.

## What the Report Records

Every dimension on the drawing, measured, with the instrument, its calibration date and the reading. The drawing revision. The material lot. The date and the machine. It takes an hour on a coordinate measuring machine for a part of ordinary complexity, and the hour is the cheapest one in the program.

A repeat run made a year later on the same fixture can be compared to the report instead of trusted. When a reading drifts, the drift is visible before it becomes a return. When the customer changes a revision, the report shows which features moved and which did not.

Without the report, the second batch is a new first article with no record of the old one.

## Ask For It

If your shop does not send a first article report, ask for one. If they cannot produce one, ask why. The answer tells you how the rest of the program will go.

> The first part proves the drawing once. The report is how it stays proven.

As-machined, bead-blasted, anodized, plated. Each is a different process, and two of them are done by someone else. A drawing with no finish note is quoted as-machined, and the conversation happens after the quote instead of before it.

## Say the Quantity Per Release

One part and one thousand parts are quoted differently, because a fixture is worth building for one of them. The annual volume matters even when the first order is small.

`scripts/lib/frontmatter.mjs`:

```js
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';

/**
 * Enough YAML for this repo's frontmatter: scalars, quoted scalars, booleans
 * and INLINE arrays (`["a", "b"]`). Block arrays and nested objects are left
 * as raw text under their key, which is fine for the scripts that use this:
 * they read the fields the kit writes, and the kit writes inline arrays.
 */
export function frontmatter(source) {
  const match = source.match(/^---\n([\s\S]*?)\n---\n?/);
  if (!match) return { data: {}, body: source, found: false };
  const data = {};
  for (const line of match[1].split('\n')) {
    const kv = line.match(/^([A-Za-z_][\w-]*):\s*(.*)$/);
    if (!kv) continue;
    const [, key, raw] = kv;
    // A trailing "  # comment" is stripped; a # inside quotes ("#0057B8") has no space before it and survives.
    const value = raw.trim().replace(/\s+#.*$/, '');
    if (value.startsWith('[')) {
      try {
        data[key] = JSON.parse(value);
      } catch {
        data[key] = value;
      }
    } else if (value === 'true' || value === 'false') {
      data[key] = value === 'true';
    } else {
      data[key] = value.replace(/^["'](.*)["']$/s, '$1');
    }
  }
  return { data, body: source.slice(match[0].length), found: true };
}

/** Every .md file under a folder, recursively, sorted. */
export function walkMarkdown(dir, out = []) {
  for (const entry of readdirSync(dir).sort()) {
    const full = join(dir, entry);
    if (statSync(full).isDirectory()) walkMarkdown(full, out);
    else if (entry.endsWith('.md')) out.push(full);
  }
  return out;
}

- [ ] **Step 5: `scripts/content-check.mjs`**

```js
/**
 * Enforce the editorial settings in content/site.md across every content file.
 *
 *   noEmDash      an em dash anywhere is an ERROR
 *   bannedWords   a banned word, whole-word, case-insensitive, is an ERROR
 *   noPricing     a currency amount or a percentage is a WARNING with the
 *                 line, because legitimate figures exist and an editor decides
 *
 * content/site.md itself is not scanned: it holds the banned list.
 *
 * Run: node scripts/content-check.mjs   (wired into `npm run build`)
 */
import { readFileSync } from 'node:fs';
import { join, relative } from 'node:path';
import { fileURLToPath } from 'node:url';
import { frontmatter, walkMarkdown } from './lib/frontmatter.mjs';

const root = fileURLToPath(new URL('..', import.meta.url));
const siteFile = join(root, 'content', 'site.md');
const site = frontmatter(readFileSync(siteFile, 'utf8')).data;

const noEmDash = site.noEmDash !== false;
const noPricing = site.noPricing !== false;
const banned = Array.isArray(site.bannedWords) ? site.bannedWords : [];

const escape = (s) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
const bannedPatterns = banned.map((word) => new RegExp(`\\b${escape(word)}\\b`, 'i'));
const PRICE = /(?:\$|€|£|\bCAD\b|\bUSD\b|\bEUR\b)\s?\d[\d,]*(?:\.\d+)?|\b\d+(?:\.\d+)?\s?%/;

const errors = [];
const warnings = [];

for (const file of walkMarkdown(join(root, 'content'))) {
  if (file === siteFile) continue;
  const rel = relative(root, file);
  readFileSync(file, 'utf8').split('\n').forEach((line, i) => {
    const at = `${rel}:${i + 1}`;
    if (noEmDash && /—/.test(line)) errors.push(`${at}: em dash`);
    bannedPatterns.forEach((pattern, j) => {
      if (pattern.test(line)) errors.push(`${at}: banned word "${banned[j]}"`);
    });
    if (noPricing && PRICE.test(line)) {
      warnings.push(`${at}: looks like a price or percentage: ${line.trim().slice(0, 80)}`);
    }
  });
}

for (const w of warnings) console.warn(`content-check WARNING ${w}`);
if (errors.length > 0) {
  throw new Error(`content-check: ${errors.length} error(s):\n  ${errors.join('\n  ')}`);
}
console.log(`content-check: ok (${warnings.length} warning${warnings.length === 1 ? '' : 's'})`);
```

/**
 * Kickoff: turn intake/brand.md and intake/sitemap.md into a configured repo.
 *
 * Writes, and only these:
 *   content/site.md                  identity, services, editorial settings
 *   src/styles/tokens.css            the block between the BRAND markers
 *   public/assets/brand/*            the seven fixed-name assets
 *   content/work/hero-videos.md      the Default pool: the reel URL or nothing
 *   content/landing/<id>.md          frontmatter of each section row (created
 *                                    with a stub body when missing)
 *   wrangler.jsonc                   the worker name
 *   SITEMAP.md                       sections, pages and the redirect table
 *
 * Idempotent: the same intake produces the same files. Stops before writing
 * anything when a required field is empty, and lists the fields.
 *
 * Usage: node scripts/kickoff.mjs [--brand path] [--sitemap path] [--no-build]
 */
import { copyFileSync, existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, join, relative, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';
import { execSync } from 'node:child_process';
import { frontmatter } from './lib/frontmatter.mjs';

const root = fileURLToPath(new URL('..', import.meta.url));

/* ------------------------------------------------------------------ args */

const args = process.argv.slice(2);
const opt = (flag, fallback) => {
  const i = args.indexOf(flag);
  return i >= 0 && args[i + 1] ? args[i + 1] : fallback;
};
const brandPath = resolve(root, opt('--brand', 'intake/brand.md'));
const sitemapPath = resolve(root, opt('--sitemap', 'intake/sitemap.md'));
const noBuild = args.includes('--no-build');

const rel = (p) => relative(root, p);

/* --------------------------------------------------------------- brand */

const REQUIRED = [
  'name', 'legalName', 'domain', 'city', 'region', 'country', 'countryCode', 'email',
  'accent', 'secondary', 'tertiary', 'neutral', 'dark', 'fontSans', 'fontCondensed', 'fontMono',
  'language', 'nextStepLines', 'stagingWorker',
  'logo', 'logoWhite', 'icon', 'ogImage', 'favicon', 'favicon32', 'appleTouchIcon',
];
const ASSET_NAMES = {
  logo: 'logo.svg',
  logoWhite: 'logo-white.svg',
  icon: 'icon.svg',
  ogImage: 'og-image.jpg',
  favicon: 'favicon.svg',
  favicon32: 'favicon-32.png',
  appleTouchIcon: 'apple-touch-icon.png',
};

if (!existsSync(brandPath)) fail(`${rel(brandPath)} does not exist`);
if (!existsSync(sitemapPath)) fail(`${rel(sitemapPath)} does not exist`);

const brand = frontmatter(readFileSync(brandPath, 'utf8')).data;
const empty = (v) => v === undefined || v === '' || (Array.isArray(v) && v.length === 0);
const missing = REQUIRED.filter((key) => empty(brand[key]));
if (missing.length > 0) fail(`${rel(brandPath)} is missing: ${missing.join(', ')}`);
if (brand.phone && empty(brand.phoneHref)) fail(`${rel(brandPath)}: phoneHref is required when phone is set`);
for (const key of ['accent', 'secondary', 'tertiary', 'neutral', 'dark']) {
  if (!/^#[0-9A-Fa-f]{6}$/.test(brand[key])) fail(`${rel(brandPath)}: ${key} must be a six-digit hex colour, got ${brand[key]}`);
}
if (brand.ctaLines && brand.ctaLines.length !== 0 && brand.ctaLines.length !== 3) fail(`${rel(brandPath)}: ctaLines needs three entries or []`);
if (!Array.isArray(brand.nextStepLines) || brand.nextStepLines.length !== 2) fail(`${rel(brandPath)}: nextStepLines needs exactly two entries`);

const assetSources = {};
for (const [key, name] of Object.entries(ASSET_NAMES)) {
  const source = resolve(dirname(brandPath), brand[key]);
  if (!existsSync(source)) fail(`${rel(brandPath)}: ${key} points at ${brand[key]}, which does not exist`);
  const want = name.split('.').pop();
  const got = source.split('.').pop().toLowerCase();
  if (want !== got) fail(`${rel(brandPath)}: ${key} must be a .${want} file, got .${got}`);
  assetSources[name] = source;
}

/* ------------------------------------------------------------- sitemap */

const sitemapSource = readFileSync(sitemapPath, 'utf8');

function table(source, header) {
  const start = source.indexOf(header);
  if (start < 0) fail(`${rel(sitemapPath)} has no "${header}" table`);
  const rows = [];
  for (const line of source.slice(start).split('\n').slice(2)) {
    if (!line.startsWith('|')) break;
    rows.push(line.split('|').slice(1, -1).map((c) => c.trim().replace(/^`(.*)`$/, '$1')));
  }
  return rows;
}

const KINDS = new Set(['services', 'about', 'work', 'case-studies', 'resources', 'contact']);
const sections = table(sitemapSource, '| Id | Kind | Title | URL | Order | Stage | Include |').map(
  ([id, kind, title, url, order, stage, include]) => ({ id, kind, title, url, order: Number(order), stage: stage === 'yes', include: include !== 'no' }),
);
if (sections.length === 0) fail(`${rel(sitemapPath)}: the sections table is empty`);
for (const s of sections) {
  if (!/^[a-z0-9-]+$/.test(s.id)) fail(`${rel(sitemapPath)}: section id "${s.id}" must be lowercase kebab-case`);
  if (!KINDS.has(s.kind)) fail(`${rel(sitemapPath)}: section "${s.id}" has unknown kind "${s.kind}"`);
  if (!s.url.startsWith('/')) fail(`${rel(sitemapPath)}: section "${s.id}" url must start with /`);
  if (!Number.isInteger(s.order)) fail(`${rel(sitemapPath)}: section "${s.id}" order must be a whole number`);
}
const redirects = table(sitemapSource, '| From | To | Code |').map(([from, to, code]) => ({ from, to, code }));
const pagesStart = sitemapSource.indexOf('## Pages');
const pagesEnd = sitemapSource.indexOf('## Redirects');
const pagesBlock = pagesStart >= 0 && pagesEnd > pagesStart ? sitemapSource.slice(pagesStart, pagesEnd).trim() : '';

/* -------------------------------------------------------------- writes */

const q = (v) => JSON.stringify(v ?? '');
const arr = (v) => JSON.stringify(Array.isArray(v) ? v : []);
const optionalLine = (key, v) => (empty(v) ? '' : `${key}: ${q(v)}\n`);

const siteMd = `---
name: ${q(brand.name)}
legalName: ${q(brand.legalName)}
${optionalLine('tagline', brand.tagline)}domain: ${q(brand.domain.replace(/\/$/, ''))}
${optionalLine('founded', brand.founded)}city: ${q(brand.city)}
region: ${q(brand.region)}
country: ${q(brand.country)}
countryCode: ${q(brand.countryCode)}
${optionalLine('street', brand.street)}${optionalLine('postalCode', brand.postalCode)}${optionalLine('phone', brand.phone)}${optionalLine('phoneHref', brand.phoneHref)}email: ${q(brand.email)}
sameAs: ${arr(brand.sameAs)}
areaServed: ${arr(brand.areaServed)}
${optionalLine('gtmId', brand.gtmId)}${optionalLine('formEndpoint', brand.formEndpoint)}${optionalLine('fontsHref', brand.fontsHref)}language: ${q(brand.language)}
bannedWords: ${arr(brand.bannedWords)}
noPricing: ${brand.noPricing !== false}
noEmDash: ${brand.noEmDash !== false}
${Array.isArray(brand.ctaLines) && brand.ctaLines.length === 3 ? `ctaLines: ${arr(brand.ctaLines)}\n` : ''}${optionalLine('ctaBadge', brand.ctaBadge)}nextStepLines: ${arr(brand.nextStepLines)}
marquee: ${arr(brand.marquee)}
sample: false
---

This file is the site's identity. Written by scripts/kickoff.mjs from
${rel(brandPath)}; edit either, but kickoff overwrites this file when it runs.
`;

const tokensPath = join(root, 'src/styles/tokens.css');
const tokens = readFileSync(tokensPath, 'utf8');
if (!/\/\* BRAND:START \*\/[\s\S]*?\/\* BRAND:END \*\//.test(tokens)) fail('src/styles/tokens.css has no BRAND:START/END markers');
const brandBlock = `/* BRAND:START */
  --brand-accent:    ${brand.accent.toUpperCase()};  /* CTAs, dots, highlights, hover, accent text */
  --brand-secondary: ${brand.secondary.toUpperCase()};  /* H2 colour, dark-button hover */
  --brand-tertiary:  ${brand.tertiary.toUpperCase()};  /* supporting colour, light-mode links */
  --brand-neutral:   ${brand.neutral.toUpperCase()};  /* light lines and surfaces */
  --brand-dark:      ${brand.dark.toUpperCase()};  /* dark surfaces base */
  --font-sans:       ${brand.fontSans};
  --font-condensed:  ${brand.fontCondensed};
  --font-mono:       ${brand.fontMono};
  /* BRAND:END */`;
const nextTokens = tokens.replace(/\/\* BRAND:START \*\/[\s\S]*?\/\* BRAND:END \*\//, brandBlock);

const heroVideos = `---
title: "Hero video assignments"
---

# Hero videos

Every page carries an edge-to-edge looping background video chosen here. Vimeo only: YouTube cannot be made chrome-free.

## How to use this file

One URL under a heading means every page in that section uses it. Two or more spread across the section by a stable hash of the route. Sections match the first URL segment. Anything else falls to \`## Default\`. Delete every link and no page shows a video.

## Default

${empty(brand.heroVideo) ? '(no reel yet)' : brand.heroVideo}
`;

const wranglerPath = join(root, 'wrangler.jsonc');
const wrangler = readFileSync(wranglerPath, 'utf8').replace(/"name":\s*"[^"]*"/, `"name": ${q(brand.stagingWorker)}`);

const sectionRows = sections
  .map((s) => `| ${s.id} | ${s.kind} | ${s.title} | ${s.url} | ${s.order} | ${s.stage ? 'yes' : 'no'} | ${s.include ? 'yes' : 'no'} |`)
  .join('\n');
const redirectRows = redirects.map((r) => `| \`${r.from}\` | \`${r.to}\` | ${r.code} |`).join('\n');
const sitemapMd = `# Site structure

Domain: **${brand.domain.replace(/^https?:\/\//, '').replace(/\/$/, '')}**

Written by \`scripts/kickoff.mjs\` from \`${rel(sitemapPath)}\`. The redirect table
at the end is read by \`scripts/postbuild.mjs\` and becomes \`dist/_redirects\`;
everything above it is documentation. Edit the intake file and run kickoff
rather than editing this file.

## Sections

| Id | Kind | Title | URL | Order | Stage | Include |
|---|---|---|---|---|---|---|
${sectionRows}

${pagesBlock ? `${pagesBlock}\n\n` : ''}## Redirects

| From | To | Code |
|---|---|---|
${redirectRows}${redirectRows ? '\n' : ''}`;

/** Rewrite one landing file's frontmatter, keeping its body and any keys the sitemap does not own. */
function landingFile(section) {
  const path = join(root, 'content/landing', `${section.id}.md`);
  const existing = existsSync(path) ? readFileSync(path, 'utf8') : null;
  const match = existing?.match(/^---\n([\s\S]*?)\n---\n?([\s\S]*)$/);
  const keep = [];
  const OWNED = new Set(['title', 'url', 'order', 'kind', 'stage', 'published']);
  if (match) {
    for (const line of match[1].split('\n')) {
      const key = line.match(/^([A-Za-z_][\w-]*):/)?.[1];
      if (!key || !OWNED.has(key)) keep.push(line);
    }
  }
  // A landing file the kickoff has to create is sample content until someone writes it.
  if (!match) keep.push('sample: true');
  const owned = [
    `title: ${q(section.title)}`,
    `url: ${q(section.url)}`,
    `order: ${section.order}`,
    `kind: ${q(section.kind)}`,
    ...(section.kind === 'services' ? [`stage: ${section.stage}`] : []),
    ...(section.include ? [] : ['published: false']),
  ];
  const body = match ? match[2] : `\n# ${section.title}\n`;
  return { path, content: `---\n${[...owned, ...keep].join('\n')}\n---\n${body}` };
}

const landingWrites = sections.map(landingFile);

/* ------------------------------------------------------------- commit */

writeFileSync(join(root, 'content/site.md'), siteMd);
writeFileSync(tokensPath, nextTokens);
mkdirSync(join(root, 'public/assets/brand'), { recursive: true });
for (const [name, source] of Object.entries(assetSources)) copyFileSync(source, join(root, 'public/assets/brand', name));
mkdirSync(join(root, 'content/work'), { recursive: true });
writeFileSync(join(root, 'content/work/hero-videos.md'), heroVideos);
writeFileSync(wranglerPath, wrangler);
writeFileSync(join(root, 'SITEMAP.md'), sitemapMd);
mkdirSync(join(root, 'content/landing'), { recursive: true });
for (const { path, content } of landingWrites) writeFileSync(path, content);
for (const s of sections.filter((x) => x.kind === 'services')) mkdirSync(join(root, 'content/services', s.id), { recursive: true });

console.log(`kickoff: wrote content/site.md, tokens brand block, ${Object.keys(assetSources).length} brand assets, hero-videos.md, wrangler.jsonc, SITEMAP.md and ${landingWrites.length} landing files for ${brand.name}.`);

if (!noBuild) {
  console.log('kickoff: building (staging)');
  execSync('npm run build', { cwd: root, stdio: 'inherit', env: { ...process.env, STAGING: '1' } });
}

function fail(message) {
  console.error(`kickoff: ${message}`);
  process.exit(1);
}

```markdown
# CLAUDE.md: the Astro Kit

> Read this fully before writing any code.

## What this is

A template repository for client websites built on Astro: fully static, no
CMS, content as Markdown, deployed to Cloudflare as plain files. A new project
starts with "Use this template", fills `intake/`, and runs the kickoff. See
`KIT.md` for the eight steps and `TEMPLATE-ANATOMY.md` for how the templates
decompose.

## Decisions that do not reopen

1. **Astro, static, no adapter.** Every route is prerendered.
2. **No CMS.** Content is Markdown in `content/`.
3. **Cloudflare Workers static assets.** `dist/` is plain files; `_headers` and
   `_redirects` are generated by `scripts/postbuild.mjs`.
4. **Design System C is the visual spec**, `docs/design-system-c.html`. Type
   scale, grid, spacing, motion and components do not change per client. Only
   colours, fonts and logos do, through the brand block in `tokens.css` and
   `public/assets/brand/`.
5. **Six section kinds:** services, about, work, case-studies, resources,
   contact. Services and about choose their URL; the others are fixed.
6. **The hero H1 wraps.** Never restore `white-space: nowrap`.
7. **Legal documents render through Astro's Markdown pipeline**, not the
   Master template.

## The rules that keep a site consistent

1. **The content collection is the source of truth** for sections, menus,
   related rows and every count. Never hard-code a list. Adding a Markdown file
   must add its route, its menu entry and its count with no code change.
2. **Everything about the client lives in three places:** `content/site.md`,
   the BRAND block in `src/styles/tokens.css`, and `public/assets/brand/`.
   Nothing under `src/` may carry a client value.
3. **Extract by type, place by slot.** `src/lib/anatomy.ts` maps Markdown to
   template slots by kind, not document order.
4. **Never invent copy.** A slot with no source is omitted, not filled.
5. **The first paragraph of a page's Markdown is the lede.** Two or three
   sentences. Fix the source, never split a paragraph in code.
6. **Scroll locks go on `<html>`, never `<body>`.**
7. **Fixed overlays live outside `.page-root`.** `.hero` and `.page-root` both
   clip fixed descendants.
8. **A section with nothing to show is not built.** No menu row, no route, no
   sitemap entry, one warning naming the landing file.

## Non-negotiables

1. Ship every redirect in `SITEMAP.md`.
2. One H1 per page, no skipped heading levels.
3. JSON-LD: Organization, BreadcrumbList, and the type each page earns.
4. A canonical URL per page.
5. WCAG 2.1 AA: visible focus, keyboard navigation, `prefers-reduced-motion`.
6. A production build refuses sample content (`scripts/sample-guard.mjs`) and
   editorial slips (`scripts/content-check.mjs`).

## Commands

```bash
npm run kickoff        # intake -> configuration, then a staging build
npm run build          # guards, blog check, astro build, headers and redirects
npm run preview        # build, then serve through wrangler WITH headers
npm run check          # astro check
npm test               # the kit's own tests (several builds, minutes)
npm run blog-tags      # assign categories and tags from content/taxonomy.md
npm run video-meta     # video dimensions and poster frames
```

Verify through `npm run preview`, never `astro dev`, which applies neither
`_headers` nor `_redirects`.

## Editorial settings

They live in `content/site.md`. The build enforces three of them: banned words
and em dashes are errors, a price or percentage is a warning. The language
variant sets `<html lang>` and `og:locale` and is a writing rule, not a check.
The defaults are the studio's; a client project changes them in
`intake/brand.md`. Do not add a rule in code.

## Traps already hit

- **The build image runs npm 10.** Regenerate the lockfile with
  `npx npm@10 install --package-lock-only`.
- **Never hard-code a media aspect ratio.** Hero videos scale to cover using
  each source's real aspect from `content/work/video-meta.json`.
- **`script-src` uses `'strict-dynamic'`**, so every script must stay inline
  for `postbuild.mjs` to hash. A `<script src>` is blocked and the build throws.
  `'unsafe-inline'` is inert alongside hashes; never add it.
- **`content/blog` does not recurse.** A post in a subfolder is invisible.
- **Slot 4 lifts images out of the copy by default.** Articles pass
  `inlineFigures`.
- **Vite inlines assets under 4KB as data URIs**, so counting figure files in
  `dist/` under-counts.
- **`schemaType="Article"` on `MasterPage` emits a second Article.** Pass
  `WebPage` and own the Article in `extraSchema`.
- **`new Date('2026-08-30')` is UTC midnight.** Parse `${iso}T00:00:00`.
- **`aspect-ratio` loses to Astro's width and height attributes.** A cropped
  `<Image>` needs `height: auto`.
- **Astro scopes component CSS**, so a rule cannot reach a node built at
  runtime. Mark it `:global()` through a static parent.
- **`figures.ts` resolves blog figures by bare filename** across one folder;
  prefix them with the post slug. Case study imagery resolves by full path.
- **`--pg-bg`, `--pg-fg` and `data-theme` live on `body`**, not `:root`.
- **The hero H1 reveal looks like a clipping bug** for its first second.
- **A hidden browser pane reports a 0x0 viewport**, cannot hold focus, and
  starves `requestAnimationFrame`. Force a real viewport before measuring.
- **Never scope a button variant to a tag.** `.aps-btn.aps-btn-primary`, not
  `a.aps-btn-primary`, and never lower specificity to fix a clash.
- **`getComputedStyle` mid-transition reports the start colour.** Settle for
  1.5s after a theme change before measuring contrast.
- **`frame-ancestors 'none'` blocks same-origin iframe harnesses.** Use real
  viewports.
- **iOS overscroll paints from `<html>`.** `html { background: #000 }` stays.
- **YouTube cannot be made chrome-free.** Hero loops are Vimeo only.
- **An inline `style` attribute outranks every `:hover` rule.**
- **A wildcard host does not match the bare domain.** List both in the CSP.
- **`content/work/videos.md` titles may contain `|`.** The parser locates the
  URL cell; a numbered row with no Vimeo or YouTube URL throws.

## Working agreements

- Ask before structural decisions not covered here.
- One component per file. TypeScript throughout.
- Do not claim something works until it has been verified. Show the evidence.
```
